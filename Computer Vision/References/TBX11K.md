# TBX11K

> [!info] Supporting Material
> - [[Foundation X.pdf]]

> [!summary] Summary
> In these notes, TBX11K is a chest X-ray dataset with classification labels and bounding boxes. That description comes from Foundation X. Image counts and class definitions are not recorded here.

> [!important] Key Points
> - Supervision named so far: classification labels and bounding boxes.
> - No segmentation labels are mentioned.
> - Source: Foundation X, page 1.
