# Semantic Segmentation

> [!summary] Summary
> Semantic segmentation assigns a class label to every pixel. It is one of the three usual subcategories of image segmentation, and it tells a model what kind of thing each pixel belongs to without separating individual object instances.

> [!important] Key Points
> - The output is a class label per pixel.
> - It is a subcategory of image segmentation.
> - It does not, by itself, separate two objects of the same class.
> - PSPNet is the semantic segmentation model cited for anatomical parts in the chest X-ray notes.

## Definition

Semantic segmentation assigns a class label to pixels with a deep learning model. It is one of three subcategories of [[image segmentation]]. (via [IBM](https://www.ibm.com/think/topics/semantic-segmentation))

## Related Concepts

- [[image segmentation]] - the broader task of partitioning an image into regions.
- [[PSP-Net]] - a semantic segmentation model used for anatomical parts.
- [[Mask R-CNN]] - instance segmentation, which separates individual objects.
