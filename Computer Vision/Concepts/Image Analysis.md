# Image Analysis

> [!info] Supporting Material
> - [[Foundation X.pdf]]

> [!summary] Summary
> Image analysis extracts meaningful information from images, usually digital images, by digital image processing. Tasks range from reading a barcode to recognizing a face. In these notes, combining classification, segmentation, and localization in one model is treated as a way to improve that analysis.

> [!important] Key Points
> - The input is an image, and the output is information extracted from it.
> - Computers handle large data and quantitative measurement. Human vision is still stronger for some higher-level judgments in medicine, security, and remote sensing.
> - Edge detectors and neural networks are among the tools built from models of visual perception.
> - Foundation X argues that one model covering classification, segmentation, and localization improves image analysis.

> [!note] Definition
> Image analysis, or imagery analysis, is the extraction of meaningful information from images, mainly digital images, by means of digital image processing ([source](https://en.wikipedia.org/wiki/Image_analysis#cite_note-solomonbreckon10fundamentals-1)). Tasks can be as simple as reading barcoded tags or as sophisticated as identifying a person from their face.
>
> Computers are indispensable for the analysis of large amounts of data, for tasks that require complex computation, or for the extraction of quantitative information. The human visual cortex is an excellent image analysis apparatus, especially for extracting higher-level information, and for many applications — including medicine, security, and remote sensing — human analysts still cannot be replaced by computers. For this reason, many important image analysis tools such as edge detectors and neural networks are inspired by human visual perception models.
