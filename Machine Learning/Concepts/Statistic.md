# Statistic

> [!info] Supporting Material
> - [[Intro to ML - Ethem Alpaydin]]

> [!summary] Summary
> A statistic is any value calculated from a given sample. These notes record that definition and do not yet distinguish particular statistics such as the sample mean or sample variance.

> [!important] Key Points
> - It is computed from the sample.
> - The sample mean and sample variance used in the density notes are statistics.
> - An estimator is a statistic used to guess a parameter of the assumed distribution.

## Notes

- Any value calculated from a given sample.

## Related Concepts

- [[Parametric Methods]] - uses sample statistics as parameter estimates.
- [[Maximum Likelihood Estimation]] - turns a statistic into a parameter estimate.
