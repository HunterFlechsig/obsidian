# Overfitting

> [!info] Supporting Material
> - [[Foundation X.pdf]]

> [!summary] Summary
> Overfitting is a model fitting its training data, including noise, so well that it fails to generalize. The only case recorded here is Foundation X: training one model on many tasks and several datasets can cause overfitting.

> [!important] Key Points
> - The recorded claim is about multi-task, multi-dataset training, not a general definition worked out in the vault.
> - Foundation X treats that integration as a source of overfitting.
> - The note does not yet record a remedy.

## Notes

- Integrating many tasks on several datasets to train a model causes overfitting. [[Foundation X.pdf#page=1&annotation=1228R|Foundation X, p.1]]
